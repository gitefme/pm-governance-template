# Idea Inbox

Non-formal holding area for raw ideas, possible tasks, questions, and discussion topics. Ideas are not scheduled work and have no implementation commitment.

## Rules

- Use stable `I-###` IDs.
- Preserve exact user input; confirm any Codex-authored summary, assessment, or expansion before storing it.
- Do not assign task status, stage, priority, acceptance criteria, planning horizon, or plan files.
- Promotion requires a separately confirmed `T-###` formulation in `BACKLOG.md`.
- Move promoted, rejected, or resolved ideas to `IDEA_ARCHIVE.md`.

## Idea Template

```md
- I-000 Short working title
  - Captured: YYYY-MM-DD
  - User Inputs: optional; omit when none were provided
  - Codex Additions: optional; confirm before storage
  - Raw Idea:
  - Open Questions:
  - Related Context:
```
