# Idea Archive

Historical registry for promoted, rejected, or otherwise resolved ideas. It is not an implementation queue.

## Rules

- Preserve the stable `I-###` ID and confirmed context needed to understand the outcome.
- Record one outcome: `Promoted`, `Rejected`, or `Resolved`.
- A promoted idea must reference an existing formal task.
- Keep archived ideas outside normal backlog summaries unless explicitly requested.

## Archive Template

```md
- I-000 Short working title
  - Captured: YYYY-MM-DD
  - Archived: YYYY-MM-DD
  - Outcome: Promoted | Rejected | Resolved
  - Promoted to: T-000
  - Summary:
```
