# Roadmap Example

Reference only; adopt using [the registration procedure](../GOVERNANCE_EXTENSIONS.md#adoption-and-ownership).

```md
# Outcome Roadmap

- Formulation Status: proposed
- Storage Authorization: date and explicit scope of write-first authorization
- Basis: confirmed user outcomes and linked decision evidence
- Updated: YYYY-MM-DD

BACKLOG.md owns task status and membership. The executive plan owns milestones.
This document neither activates work nor promises calendar completion.

| Outcome | Task/epic references | Transition gate and evidence | Open decision |
| --- | --- | --- | --- |
| First bounded outcome | Existing task and epic links | Specific integrated acceptance | Decision reference or None |

Sequence follows prerequisites. Keep later horizons deferred until separately authorized.
```
